Wiring

Tap an output terminal (right side of a block), then tap an input terminal (left side of a block) to connect them. Tap the output again to cancel.

Lamps and Motors have both an input and an output terminal, so their state can feed into other blocks (gates, timers, counters, or another output).

Drag block headers to move. Tap the × on a wire or block to remove it.

Double-tap a block's ID label to rename it.

Instruction List
Syntax: TARGET = EXPR using AND OR XOR NOT ( )
LMP1 = PB1 OR TMR1.Q
TMR1.IN = SW1 AND NOT PB2
TMR1.PT = 3000 // preset ms, numeric only
CTR1.PV = 5 // preset count, numeric only
REL1.SET = PB1 · REL1.RESET = PB2 // SET/RESET latch inputs
AND1 = PB1 AND SW1 · NOT1 = NOT (PB1) · XOR1 = PB1 XOR SW1
Timer On (TMR) delays turning on; Timer Off (TOF) delays turning off; Counter (CTR) counts rising edges on IN and compares CV to PV using its ≥ / ≤ / = dropdown. Its wired RESET input forces CV back to 0 and inhibits counting while live — same idea as Relay's SET/RESET, plus a manual "Reset CV" button for a no-wiring reset.
Relay (REL) is a SET/RESET latch: SET drives Q true, RESET drives Q false, and Q holds its last state when neither is live. Its dropdown picks which one wins if both are live at once (default: Reset dominant).
Lamp and Motor outputs each have an output terminal too, so you can wire one into another gate, timer, counter, or output.
E-Stop (EST) behaves like a latching switch, wired the same way as a Toggle — tap once to trip it (output goes false), tap again to reset.
The Instruction List tab shows the same logic as accumulator-style IL (LD / AND / OR / XOR / NOT / ST) — it's a read-only view generated from the Structured Text.
